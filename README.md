# Axlori Tech

A premium, futuristic multi-page portfolio website for **Axlori Tech** — an AI and software technology company building intelligent digital experiences, AI-powered systems, automation, and innovative technology.

## Experience

The site combines a dark cinematic atmosphere with editorial typography, a vertical grid system, glassmorphism navigation, purple energy lighting, and a custom abstract AI entity visual.

## Routes

- `/` — Home
- `/about` — Vision, philosophy, and approach
- `/services` — Core capabilities
- `/projects` — Selected work and GitHub portfolio
- `/contact` — Contact details and inquiry form

## Tech stack

- Next.js 14
- React 18
- CSS with responsive editorial layouts
- `next/font` for typography
- `lucide-react` available for interface iconography

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
